# DSA Practice Solutions

This repository contains my daily problem-solving practice from competitive
programming and DSA platforms. Each solution is kept in a dedicated file with
a short problem description, examples, constraints, and the final approach.

## 🛠️ Tech Stack

* SQL
* Java
* JavaScript
* Git & GitHub

## 🌐 Platforms

* LeetCode
* GeeksForGeeks
* CodeChef

## 📁 Repository Structure

```text
DSA-practice/
├── LeetCode/
│   ├── easy/
│   ├── medium/
│   └── hard/
├── GeeksforGeeks/
├── Codechef/
└── sql/
```

LeetCode problems are organized only by difficulty. Each problem has one
solution file, named using the problem number and a readable title, for
example:

```text
LeetCode/easy/0001_two_sum.java
LeetCode/medium/0189_rotate_array.java
LeetCode/easy/2620_counter.js
```

## 📌 Practice Principles

* Keep one problem per file.
* Preserve the original solution while improving documentation.
* Use consistent, descriptive filenames.
* Keep problem descriptions free of external links and images.
* Prefer consistency and understanding over solving a large number of problems.

## 📈 Goal

* Improve problem-solving skills
* Build daily coding consistency
* Maintain a clean and searchable solution library
* Strengthen revision through clear explanations

## ⚠️ Note

Problem statements are summarized in my own words for learning and revision.
This repository is intended for educational purposes only.
